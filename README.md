# Mensageria CRM — instaladores

Instaladores do app **Mensageria CRM** (Windows e Mac). Este repositório guarda só os instaladores e os arquivos de atualização; o código fica em outro lugar.

**Baixe a versão mais recente em [Releases](../../releases/latest).**

## Windows
Baixe `MensageriaCRM-Setup-x.y.z.exe` e execute. Na primeira instalação, o Windows mostra "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Depois disso o app se atualiza sozinho.

## Mac
- Chip Apple (M1, M2, M3…): `MensageriaCRM-x.y.z-arm64.dmg`
- Intel: `MensageriaCRM-x.y.z-x64.dmg`

Abra o arquivo e arraste o app para **Aplicativos**. Na primeira vez, o Mac avisa que não pode verificar o app: vá em **Ajustes do Sistema → Privacidade e Segurança → Abrir mesmo assim**. Quando houver versão nova, o app avisa e mostra **Baixar**; instale por cima (as contas continuam).
